Inside the build

The story
The brief

A travel platform for the world, not just India

The founder wanted a booking platform that didn't read like every other domestic OTA. The audience is global — backpackers, digital nomads, slow-travel families. The editorial voice had to match.

Stack
  • Astro
  • Vercel
  • llms.txt + JSON-LD
  • Revenue-share API
What we shipped

Faster pages, AI-discoverable inventory

Astro for content speed. llms.txt + structured data so AI assistants quote the inventory accurately. A revenue-share back-end the founder updates without touching code. AI-referred traffic showed a measurable lift within weeks.

About this project

InHimalayas is a revenue-share booking platform for resorts and stays across the Himalayas, built by Divyansh Sood Studio for a global travel audience.

It ships with an llms.txt file and JSON-LD structured data so AI assistants can quote the inventory accurately — which drove a measurable lift in AI-referred traffic within weeks.

Astro on Vercel, with llms.txt + JSON-LD for GEO and a revenue-share back-end the founder can update without touching code.
